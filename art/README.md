# Icons

Drawn by renewable-intel; converted with `scripts/png2icon.py` (OS 3.5+
colour icons with a 4-colour image for older Workbenches, frameless).

| File | What | Size |
|---|---|---|
| `SimpleDock.info` | the program icon: SD on a dark disc, letters anti-aliased, the disc's edge blended towards dark grey (colour icons have no partial transparency) | 64 x 64 |
| `Settings.info` | the gear the dock shows for the SimpleDock icon on the dock (`Icons/Settings` in the drawer) | 44 x 46 |

`scripts/package.sh` copies them into the archive. The drawings themselves
are not in the repository.
